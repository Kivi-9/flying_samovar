# Самовар-аэростат «Пар-Облако»

`FlyingSamovar` моделирует взлёт с грузом, перелёты при разной погоде и посадку. Объём баллона определяет грузоподъёмность. Буря повреждает баллон после успешного перелёта, а ремонт и заправка доступны на земле.

## Запуск тестов

Нужен Python 3.10 или новее. Модуль и тесты используют стандартную библиотеку Python. Выполните из корня репозитория:

```sh
python -B -m unittest discover -s tests -t . -v
```

Ожидаемый результат — `Ran 24 tests` и `OK`. В наборе 20 модульных тестов (TC-01–TC-19, TC-24) и 4 сценарных (TC-20–TC-23).

## Пример

Запустите `python` в корне репозитория и выполните:

```python
from flying_samovar import FlyingSamovar

samovar = FlyingSamovar("Пар-Облако", 120, 400, 40)
samovar.take_off(cargo_kg=60)
print(samovar.fly(10, "calm"))  # 0.25 часа
samovar.land()
print(samovar.get_status())
```

После посадки самовар находится на земле, баллон цел, груза на борту 0 кг. Пройдено 10 км, осталось 70 единиц энергии.

Расстояние задаётся в километрах, масса в килограммах, объём баллона в м³, скорость в км/ч. `fly` возвращает время в часах, `calculate_energy` — расчётный расход. Поддерживаемые значения погоды: `calm`, `tailwind`, `headwind`, `storm`.
